# Identity datasets

Identity is the first training curriculum.  The canonical copies in this
directory are the hash-verified V15 identity reference, V16 response-only
retention source, V43 conversation identity lane, and deterministic V60
preparation package.  The original V1–V59 inputs remain in
`models/` as immutable historical sources until a separate path-migration
contract handles every consumer.

No knowledge corpus is admitted into the identity lane.  The V60 hypothesis
is allowed to add only an explicitly measured, train-only V16-derived
response-only retention share; V16/V15 validation and adversarial material
remains outside training.  V60 validation is copied from V43 only.
